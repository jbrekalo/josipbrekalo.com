What I do

Tracking and data

So decisions rest on numbers that are right

  • dataLayer set up and extended for analytics and marketing tools, together with online marketing
  • Cross-domain tracking, so a visit is followed across more than one domain
  • Conversion goals and events for Kameleoon, wired into the theme
  • Visitor behaviour analysed with Hotjar and Microsoft Clarity
  • Page speed and Core Web Vitals measured with Lighthouse

A/B testing and conversion

So a change is proven before it stays

  • Full-page tests of the live product page against a completely new design
  • Cart tests, and tests of product variants and their prices
  • Every test runs from hypothesis to evaluation in Kameleoon, against conversion rate and average order value
  • Variants built in the theme itself, so even a full redesign can be tested
  • UX changes based on data and user feedback

Apps and automation

So costs and manual work go down

  • Custom subscription apps in React, Node.js and the GraphQL Admin API that replace paid apps to save costs
  • Shopify Flow automations: order tagging, Reviews.io ratings pulled through their API
  • Checkout changes with checkout UI extensions
  • Integrations between Shopify and external systems
  • Subscription, review, payment and email marketing tools connected and configured

Automated testing and quality

So a release never breaks the purchase

  • End-to-end tests with Playwright that cover the purchase, from landing on the page to checkout
  • QA across browsers and devices
  • Code reviews, refactoring and technical documentation

Stores and sections

  • Existing stores moved to a clean, maintainable theme
